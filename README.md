# Employee Management Angular UI

A simple Angular 17 application for managing employee records in memory.

## Features

- View all employees
- Filter employees by name prefix
- Add a new employee
- Edit an existing employee
- View employee details
- Delete an employee

## Tech Stack

- Angular 17
- TypeScript
- Angular Router
- Angular Forms

## Prerequisites

- Node.js 18+ (recommended)
- npm 9+

## Setup

```bash
npm install
```

## Run Locally

```bash
npm start
```

The app starts on:

- http://localhost:4200/

## Build

```bash
npm run build
```

## Project Structure

```text
src/
  app/
    add-employee/
    edit-employee/
    employee-details/
    employees-list/
    main/
    models/
    services/
```

## Notes

- Data is currently stored in memory in the employee service.
- Refreshing the page resets in-memory changes.
